# Mutation — judgement

Render your verdict. The `mutation-report` asset must be published before it.

Select `reported`: the only verdict this node has. Survivors, a failed or over-budget run, and a repo with no declared
method are all findings for the report, never reasons to hold the chunk.

Alongside your verdict, submit this node's retrospective: run `blizzard runner artifact create --name retrospective`
with a few honest lines on stdin — what went well, what didn't, and what the next node or run should know.
