# Triage — judgement

Select the route your triage rationale justifies. The rationale rides forward as the `triage-findings` asset — if you have not yet run `blizzard runner artifact create --name triage-findings` with it on stdin, do that now before recording this verdict.

Select `already-done` only on positive evidence that every work item's intent is already satisfied by the environment's current code — the chunk then closes without entering a lane. Select `harness` when the work's own subject is the agentic harness itself — a skill, a `blizzard-context` rule, a graph prompt, agent docs, or another agent-capability surface — regardless of its complexity label; the chunk migrates to the frontier-tier bas-hwf lane and starts at its build node. Select `basic` for small, well-specified work that is not harness work; the chunk migrates to the lightweight bas-dwf lane and starts at its build node. Select `advanced` for work that warrants a plan; the chunk migrates to the plan-gated adv-dwf lane and starts at its plan node.
