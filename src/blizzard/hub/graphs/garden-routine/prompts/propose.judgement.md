# Propose — judgement

Choose `proposed` if the `docket` asset holds at least one proposal, each naming the findings behind it.

Choose `none` if nothing this run found warrants a response yet — everything new is minor, already answered by a
proposal somebody has seen, or (per `propose.md`'s Shape rule) has no live id yet to cite, as a first-run bail-out
does. The findings still deliver; they are evidence, and evidence does not need a proposal to be worth keeping.

Prefer `none` over padding the docket. A run that proposes nothing and records what it saw is more useful than one that
manufactures a response so the pass looks productive.
