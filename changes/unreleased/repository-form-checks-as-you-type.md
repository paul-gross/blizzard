The board's repository create and edit forms mark the forge, the credential, and the other required fields, check each
field as it is typed, and land a refusal such as a taken slug or owner and repository on the field it concerns. The park
timeout is an explicit choice between the default and a stated whole number of hours, and a malformed timeout is refused
instead of being saved as the default. An edit saved over someone else's change since it opened is refused, keeping what
was typed.
