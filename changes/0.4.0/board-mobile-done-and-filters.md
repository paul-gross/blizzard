On the mobile board, Done (48h) lists the chunks finished in the last 48 hours, most recent first; each done card shows
when it finished and how long ago, and a divider separates the backlog from it. Tapping a count at the top — needs you,
running, ready, done (48h) — narrows the list to those chunks; tapping it again clears it.
